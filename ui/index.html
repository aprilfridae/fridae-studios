Experts

      
In a studio run, the Lead hands each part of the game to an expert. An expert left on Same as the Lead runs on the Lead's AI and the same model as the Lead, so a Lead on a big model uses up that plan faster. Pick an AI here and your choice always wins over the Lead's; once an AI is picked, the expert uses that AI's default model unless you pick one, even when it is the Lead's own AI. Only AIs installed on this computer are offered.

Texture generation

      

      

      
Without Antigravity, you get the prompt, make the image in your own Gemini chat, and it is picked up when you copy it. A key is only used if you switch it on below; Google then charges about 3 cents an image. The /texture, /particle and /decal commands always use your own chat. Textures only: never UI, icons or lettering. Cursor chats use only a key saved here, not one set in your computer's environment.
