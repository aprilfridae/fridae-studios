Experts

      
In a studio run, the Lead hands each part of the game to an expert.
Pick an AI and model for any of them; the rest run on the Lead's.

      
      
More
Now and then the Lead may start an expert on another AI or model; your rows here always win. An expert on Same as the Lead uses the Lead's model, so a Lead on a big model uses up that plan faster. Once you pick an AI, the expert uses that AI's default model unless you pick one. Only AIs installed on this computer are offered.

AI images

      
      
More
Icons, thumbnail art and UI art are made through Antigravity, and each picture uses some of your Gemini plan. One chat may start 12 an hour and one game's team 30, textures included. Off: agents ask you first.

      
Textures

      

      
More
Without Antigravity, you get the prompt, make the image in your own Gemini chat, and it is picked up when you copy it. A key is only used if you switch it on below; Google then charges about 3 cents an image. The /texture, /particle and /decal commands always use your own chat. Textures only: never UI, icons or lettering. Cursor chats use only a key saved here, not one set in your computer's environment.
